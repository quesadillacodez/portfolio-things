## 2025-05-18 - Global Search Keyboard Shortcut Pattern

**Learning:** Adding a global `Cmd+K` / `Ctrl+K` keyboard shortcut to trigger site-wide search improves power-user navigation efficiency without cluttering mobile or screen-reader experiences when styled with `kbd` badges and `aria-hidden` attributes paired with explicit `aria-label` descriptions.
**Action:** When adding keyboard shortcuts to UI triggers, hide visual shortcut badges from screen readers using `aria-hidden="true"` and provide full descriptive guidance in `aria-label`.
